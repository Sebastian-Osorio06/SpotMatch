# SpotMatch

Proyecto de desarrollo web orientado a la búsqueda y elección de lugares o alojamientos que se ajusten a las preferencias de cada persona.

## Descripción

SpotMatch combina los conceptos *Spot* (lugar) y *Match* (correspondencia) para representar la idea de encontrar opciones que encajen con las preferencias de cada usuario.

El proyecto se desarrollará progresivamente durante aproximadamente nueve meses, incorporando mejoras y nuevas funcionalidades en cada etapa.

La descripción funcional definitiva se actualizará a medida que se concreten e implementen las características del proyecto.

## Objetivos

- Desarrollar una aplicación web funcional y coherente.
- Organizar el desarrollo en diferentes etapas.
- Mantener una estructura de código y recursos clara.
- Documentar la evolución, las decisiones técnicas y las funcionalidades implementadas.
- Obtener una versión final que pueda presentarse como proyecto académico y formar parte de un portfolio profesional.

## Organización del desarrollo

El repositorio utiliza las siguientes ramas para organizar la evolución del proyecto:

| Rama | Función |
|---|---|
| `main` | Versión final del proyecto. |
| `v1` | Primera etapa de desarrollo. |
| `v2` | Segunda etapa de desarrollo. |
| `v3` | Tercera etapa de desarrollo. |
| `v4` | Cuarta etapa de desarrollo. |

Cada etapa conservará el estado del código y la documentación correspondiente a su evolución.
